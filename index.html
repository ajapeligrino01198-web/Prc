Try it yourself · Arduino sketch
#include <BluetoothSerial.h>
#include <ESP32Servo.h>
BluetoothSerial BT;
Servo steer;
const int ENA=33,IN1=25,IN2=26,IN3=27,IN4=14,ENB=13,SERVO=18;
const int CENTER=90, TURN=30;  // servo degrees
void drive(int a,int b,int c,int d){
  digitalWrite(IN1,a);digitalWrite(IN2,b);
  digitalWrite(IN3,c);digitalWrite(IN4,d);
  digitalWrite(ENA,a|b);digitalWrite(ENB,c|d);}
void setup(){BT.begin("ESP32_RaceCar");
  int p[]={IN1,IN2,IN3,IN4,ENA,ENB};
  for(int x:p)pinMode(x,OUTPUT);
  steer.setPeriodHertz(50);steer.attach(SERVO,500,2400);steer.write(CENTER);}
void loop(){if(!BT.available())return;
  switch(BT.read()){
    case 'F':drive(1,0,1,0);break;
    case 'B':drive(0,1,0,1);break;
    case 'L':steer.write(CENTER-TURN);break;
    case 'R':steer.write(CENTER+TURN);break;
    case 'C':steer.write(CENTER);break;
    case '\n':case '\r':break;  // ignore line endings sent by terminal apps
    default:drive(0,0,0,0);steer.write(CENTER);}}


Wiring diagram for the finished car. Tap a connection to trace it, tap again to clear. Use + and − (or pinch) to zoom, then scroll to pan.
Power switch: a 2-terminal rocker switch sits on battery + before the L298N 12V terminal, so one switch turns off motors, servo and ESP32 together (the ESP32 is fed from the L298N 5V output). It has no middle pin: one terminal goes to battery +, the other to 12V. Only extras needed: two short wires (22 AWG or thicker) and either solder or 6.3 mm push-on connectors. Switch the + side only, never the −.
Rating: KCD1-type rockers are typically rated 6–10 A, comfortably above what two TT motors draw even when stalled. Sizes vary by seller (2.1 × 1.5 cm is the common one), so check the listing before cutting the panel hole. The tiny 0.8 × 0.3 cm slide switch is only safe for light bench tests (about 0.3–0.5 A).
